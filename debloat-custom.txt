# Xiaomi Android TV 9 — debloat list
# Adapted from the tested list in https://github.com/Gathin23/CleanYourTV (examples/xiaomi-mitv-axso0)
# for this TV. Apply/undo with the repo's tools:
#   Apply:  $env:TV_HOST='<TV_HOST>'; powershell -File tools\disable.ps1 work\debloat-custom.txt
#   Undo:   $env:TV_HOST='<TV_HOST>'; powershell -File tools\restore.ps1 work\debloat-custom.txt
# Everything is DISABLED (pm disable-user), nothing is uninstalled. Comment out any line to keep it.
#
# Personal choices on this TV (kept commented below): voice assistant, Chromecast/Mi Cast/Miracast,
# Mi Music, Play Games, Play Movies, Mi Gallery, official YouTube (made unused by SmartTube, disabled).
#
# Notes from this firmware:
# - `svc power reboot` gets killed; reboot through adb's own reboot service instead.
# - Glance puts news/ads on the standby screen (not installed on this unit, left for other units).
# - Xiaomi's `set_auto_play` (1 out of the box) can open Live TV's empty antenna input at power-on;
#   `settings put global set_auto_play 0` makes the TV start on Home. Undo: set it to 1.
